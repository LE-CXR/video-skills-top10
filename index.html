怎么选：按你的活儿挑

同样是「AI 做视频」，这十个其实是四条完全不同的路。

一条命令就出片MoneyPrinterTurbo —— 主题进、成片出，适合批量资讯号 / 口播号。
浏览器里剪真人素材OpenCut —— 开源版剪映，网页端时间线，别再装客户端。
让编码助手剪片video-use（轻）或 OpenMontage（重）—— 素材丢进去，选段、字幕、初剪全交给 Agent。
做动效 / 数据可视化视频HyperFrames —— 写 HTML/CSS 动画，稳定渲染成 MP4，字幕与节奏最好控。
每帧都要精确控制Remotion —— 用 React 写视频，可版本化、可批量、可做模板。
产品发布片 / 广告感video-shotcraft —— 152 张镜头配方卡 + Remotion 模板，镜头语言直接抄。
主用 Seedance 等模型seedance2-skill —— 只解决一件事：把提示词写到专业级。
中文创作者 / 短剧口播chengfeng-videocut-skills —— 中文剪辑 Agent 的 Codex Plugin 入口。
本地 ComfyUI 玩家Pixelle-Video —— 文生图 → 图生视频 → TTS 全自动串起来。

榜单发生了什么变化

  • 34 天净增 5.81 万 ★，十强合计从 44.5 万涨到 50.3 万 ★（+13.1%），热度没有降温。
  • HyperFrames 涨得最凶：+15.97k ★（+32.5%），直接从第 5 挤到第 4，是这批里唯一月增一万五以上的项目。
  • OpenMontage +11.24k ★（+19.5%），把 Remotion 从第 3 挤到第 5——「Agent 全流程制片」比「React 写视频」更吃当下的红利。
  • video-shotcraft 相对涨幅第一：+4.07k ★（+50.2%），绝对数不大但爬得最快，说明「镜头语言 + Remotion 模板」这条细分路被补上了。
  • Pixelle-Video（29,104 ★）与 video-use（29,073 ★）只差 31 ★，第六第七名随时互换。
  • 尾部变化很小：seedance2-skill +0.72k、chengfeng-videocut-skills +0.09k，属于垂直场景的稳定盘。
  • 许可上，除 OpenMontage（AGPL-3.0）与 Remotion（自有 Remotion License，公司规模需授权）外，其余多为 MIT / Apache-2.0，商用友好度较高。
